# 黑流树海支持

按本机 MaaCore v6.21.1 接入，主题为 `BlackFlow`。上游协议见：
https://docs.maa.plus/zh-cn/protocol/integration.html

Vue 前端与后端自带页面均支持：

- 模式 `0`：刷奖励等级，可指定投资、快速到第三层、培育动物或目标结局的路线。
- 模式 `1`：刷源石锭。
- 模式 `30001`：刷襁褓动物，可配置猫、狗、三头犬或羽蛇。
- 模式 `30003`：刷开局，可配置准备局动物、期望奖励、准备局分队／职业组／干员，以及第一层实托邦和奖励优先级。实托邦要求目标难度至少为 6。

准备局动物最多 2 项，羽蛇最多 1 项；奖励位掩码的选项和代码见配置项提示。未指定准备局职业组或干员时沿用普通开局配置。

连战次数可配置 `0–10`，前端默认 `10`；`0` 由核心自动选择。开始探索次数可配置 `0–10`，默认 `3`。旧定时任务执行时也会将超过 10 的探索次数限制为 10，不改写数据库记录。

Vue 前端与后端自带页面中的数值配置均支持直接输入和按钮加减。次数、数量和难度按整数调整，心情阈值按 `0.1` 调整并允许直接输入小数；各字段保留相应的上下限。

后端自带页面复用 Vue 的任务定义和序列化模块。修改配置模块后，在 `web` 目录执行 `npm run build` 会自动同步；只同步可以执行 `node scripts/sync-task-config.cjs`。

验证：`go test ./...`、`go vet ./...`、`npm run test:task-config`、`npm run build`。
`MAA_NATIVE_SMOKE=1` 下的 `TestNativeABI` 还会验证本机核心接受 10 次连战及黑流树海的各模式／策略参数，不连接设备或开始游戏任务。
